# Отчет

## Доменная область приложения

Список дел: задачи можно добавлять, переименовывать, отмечать сделанными и удалять

## Стек реализации

- Бэкенд: Python, FastAPI, Uvicorn
- База данных: PostgreSQL 17, psycopg, SQL-запросы
- Фронтенд: HTML-страница на JavaScript, REST API по HTTP

## Основные сущности доменной области приложения

Задача, таблица `tasks`

| Поле | Тип | Что хранит |
|---|---|---|
| id | SERIAL | номер задачи |
| title | VARCHAR(200) | название, обязательно |
| done | BOOLEAN | сделана или нет |

CRUD:

- создать: `POST /api/tasks`
- прочитать: `GET /api/tasks`, `GET /api/tasks/{id}`
- изменить: `PUT /api/tasks/{id}`
- удалить: `DELETE /api/tasks/{id}`

## Соответствие 12 факторам

1. **Кодовая база:** один Git-репозиторий, все запуски из него, отличаются только настройки
2. **Зависимости:** библиотеки с точными версиями в `requirements.txt`, ставятся в отдельное окружение `.venv`
3. **Конфигурация:** настройки в переменных окружения `DATABASE_URL`, `HOST`, `PORT`, паролей и адресов в коде нет
4. **Сторонние службы:** база подключается по адресу из `DATABASE_URL`, для смены базы достаточно поменять переменную
5. **Сборка, релиз, выполнение:** сборка это `pip install -r requirements.txt`, релиз это код с настройками, выполнение это `python app.py`; код на ходу не меняется
6. **Процессы:** приложение ничего не хранит в памяти и на диске, все данные в PostgreSQL
7. **Привязка портов:** приложение само веб-сервер, Uvicorn слушает порт из `PORT`
8. **Параллелизм:** можно запустить несколько одинаковых копий приложения с одной базой
9. **Утилизируемость:** запуск примерно за секунду, при остановке текущие запросы дорабатываются, каждый запрос выполняется целиком или не выполняется
10. **Паритет сред:** при разработке тот же PostgreSQL 17, что и при настоящем запуске, код и библиотеки везде одинаковые
11. **Логи:** логи пишутся в stdout и stderr, собирает их среда запуска
12. **Административные процессы:** таблица создается отдельной командой `python migrate.py` с тем же кодом и настройками, что и приложение

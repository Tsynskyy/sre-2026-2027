# Отчет

Репозиторий: https://github.com/Tsynskyy/sre-2026-2027/tree/hw4

## Стек

- Приложение: Python 3.12, FastAPI, uvicorn, psycopg 3, фронтенд - статический `index.html`
- БД: PostgreSQL 17
- Кластер: minikube, манифесты в `k8s/`
- Метрики: VictoriaMetrics single-node из helm-чарта `vm/victoria-metrics-single`

## Развертывание

```sh
minikube start --driver=docker --container-runtime=docker
eval $(minikube docker-env)
docker build -t sre-tasks:1 .
kubectl apply -f k8s/

helm repo add vm https://victoriametrics.github.io/helm-charts/
helm install vm vm/victoria-metrics-single -n monitoring --create-namespace -f k8s/monitoring/vm-values.yaml
```

VictoriaMetrics через Kubernetes API находит поды с аннотацией `prometheus.io/scrape: "true"` и собирает `/metrics` с порта из `prometheus.io/port`
Этот порт должен быть объявлен в `containerPort` пода

| Под | Порт | Метрики |
|---|---|---|
| `app` | 9100 | рантайм Python, HTTP, бизнес-метрики |
| `db-0` | 9187 | PostgreSQL из сайдкара `postgres-exporter` |

## Экспортеры

Приложение - библиотека `prometheus-client`
Метрики отдает отдельный HTTP-сервер на порту 9100, путь `/metrics`, без авторизации
Service `app` публикует только порт приложения, поэтому `/metrics` доступен только изнутри кластера

- Рантайм: `process_cpu_seconds_total`, `process_resident_memory_bytes`, `process_open_fds`, `python_gc_*`, `python_info`
- HTTP: гистограмма `http_request_duration_seconds{route, status}`; `route` - шаблон пути FastAPI

PostgreSQL - готовый `postgres-exporter` вторым контейнером в поде `db`
Контейнеры пода делят сеть, поэтому он подключается к `localhost:5432`, логин и пароль берет из Secret `db`
Примеры метрик: `pg_up`, `pg_stat_database_xact_commit`, `pg_stat_activity_count`, `pg_database_size_bytes`

## Бизнес-метрики

Предметная область - список задач со статусами `todo`, `doing`, `done`

| Метрика | Что считает |
|---|---|
| `tasks_created_total` | созданные задачи |
| `tasks_completed_total` | задачи, переведенные в `done` |
| `tasks_deleted_total` | удаленные задачи |
| `tasks_duplicates_rejected_total` | отказы 409: задача с таким названием уже есть |

## Проверка

```sh
kubectl get pods -n monitoring
kubectl get svc -n monitoring
kubectl port-forward svc/vm-victoria-metrics-single-server -n monitoring 8428:8428

curl "http://localhost:8428/api/v1/targets"
curl "http://localhost:8428/api/v1/label/__name__/values"
curl "http://localhost:8428/api/v1/query?query=up"
curl "http://localhost:8428/api/v1/query?query=pg_up"
curl "http://localhost:8428/api/v1/query" --data-urlencode 'query=sum by (__name__)({__name__=~"tasks_.*_total"})'
```

В `/api/v1/targets` должно быть 3 таргета `kubernetes-pods`: 2 пода `app` и `db-0`

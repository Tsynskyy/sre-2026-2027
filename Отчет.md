## Абстракции Kubernetes

- **Pod:** в каждом поде один контейнер: приложение, PostgreSQL или миграция
- **Deployment:** держит заданное число одинаковых подов приложения, создает недостающие поды и удаляет лишние
- **StatefulSet:** запускает PostgreSQL, у пода постоянное имя `db-0` и свой диск
- **PersistentVolumeClaim:** диск 1 ГБ для данных базы, создается из `volumeClaimTemplates` StatefulSet
- **Service:** постоянное имя и адрес для группы подов
  - `db` (ClusterIP) - адрес базы внутри кластера, приложение подключается к `db:5432`
  - `app` (NodePort 30080) - вход в приложение снаружи кластера
- **Secret:** логин, пароль и `DATABASE_URL` для PostgreSQL, приложения и миграции
- **Job:** одноразовая миграция, создает таблицу `tasks`

## Взаимодействие сервисов

- браузер открывает `http://<minikube ip>:30080`, Service `app` отдает запрос готовому поду приложения
- поды приложения и миграция находят базу по имени `db` через DNS кластера
- пароли и адрес базы приходят из Secret `db`

## Логи

- приложение пишет одну строку на запрос в stdout
- Kubernetes хранит логи каждого контейнера отдельно
- их читают командой `kubectl logs deployment/app` или `kubectl logs -l app=app`
